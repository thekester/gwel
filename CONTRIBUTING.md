# Contributing

## Scope

This repository tracks research artifacts for Gwel: experiments, benchmarks, notes, and code.

## Working style

- Keep changes small and reviewable.
- Prefer reproducible scripts over manual steps.
- Document assumptions in the README or in the relevant experiment note.

## Commit messages

- Use short imperative messages.
- One logical change per commit.

## Pull requests

- Summarize what changed.
- Include reproduction steps when relevant.
- Mention any caveats or known limitations.
