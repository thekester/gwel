# Roadmap

## Current focus

- Define the benchmark protocol.
- Validate the oracle router with a small pilot.
- Measure accuracy, latency, memory, and energy on a realistic device target.

## Near-term milestones

1. Build a minimal dataset and evaluation harness.
2. Implement a baseline low-res / crop / OCR routing policy.
3. Add logging for costs and outcomes.
4. Compare supervised routing against oracle decisions.

## Out of scope for now

- Training a custom model from scratch.
- Large-scale infrastructure work before the pilot is validated.
